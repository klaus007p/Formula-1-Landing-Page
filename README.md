🏎️ **Formula 1 Landing Page**

A modern and responsive Formula 1-inspired landing page built using **HTML, JavaScript, and Tailwind CSS**. The project showcases the excitement of Formula 1 racing through a visually appealing design, smooth animations, and a fully responsive layout.

Features include a dynamic hero section, driver and team highlights, race information, interactive UI elements, and a sleek motorsport-themed design. Tailwind CSS was used to create a clean, fast, and mobile-friendly user experience while maintaining modern design standards and performance optimization.
